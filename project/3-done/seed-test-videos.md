# Seed script for a dummy videos folder

## Abstract

`python scripts\seed_test_videos.py [folder] [--force]` creates small dummy files for trying out `to-mp4`.

## Priority

Not scored; user asked for it directly.

## Timeline

- Captured: 2026-09-16
- Started: 2026-09-16
- Verified: 2026-09-16
- Done: 2026-09-16

## Details

- Default folder `test-videos/` (gitignored). Refuses a non-empty folder unless `--force`, which deletes and recreates it.
- Videos (2 s test pattern + tone, generated by ffmpeg): avi, flv, mkv (h264/aac remux, h264/ac3), mov without audio, mpg, ts, uppercase `.MKV`, webm, wmv, a non-ASCII name, gif, an existing `.mp4`, and a same-name pair (`.avi` + `.mkv`).
- Expected failures, all prefixed `error `: corrupt mkv, empty mov, truncated mov (index at end is cut off), txt, jpg, mp3.

## Verification

- Seeded `test-videos`, ran `python -m video_tools to-mp4 test-videos`: 10 converted, 3 remuxed, 1 skipped (same-name clash), 6 failed, exit 1. All 6 `error ...` files got an `.error.log`; every other file got an `.mp4`.
